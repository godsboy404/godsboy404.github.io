Linear Search

使用迴圈，從第一個開始逐一尋找目標值，到下列兩狀況之一時停止搜尋：

  • 找到目標值。
  • 搜尋完全部資料仍未找到目標值。

代码：

1int LinearSearch(const vector<int>& arr, int n) {
2    for (int i=0, i < arr.size(), i++)
3        if (arr[i] == n) return i; //找到數值與n相符者，回傳其所在索引值
4    
5    return -1;
6}

時間複雜度

最糟情況：O(n)，即目標值在最後一格，要走過每筆資料才能找到。
最佳情況：O(1)，即目標值在第一格，一找就找到。
平均情況：O(n/2)=O(n)。

空間複雜度

O(1)，僅在原陣列內搜尋，不需額外的空間暫存資料。

Binary Search

僅適用於已經按照大小順序排好的資料，每次搜尋時將資料對半切，看目標值在左半邊或右半邊，直到找到目標值為止。

详解

参考例题：给定一个升序数组，找到 target 第一次出现的位置和最后一次出现的位置。

1// 示例：
2nums = [5,7,7,8,8,10]
3target = 8
4
5// 结果：
6[3,4]
7
8// 如果不存在：
9[-1,-1]

代码：

 1int lower_bound(vector<int>& nums, int target) {
 2    int left = -1, right = nums.size();
 3    while (left+1 < right) {
 4        int mid = (left+right)/2;
 5        if (nums[mid] < target)
 6            left = mid;
 7        else right = mid; // mid >= target
 8    }
 9
10    return right;
11}

泛式 (板子)：

 1int left = -1, right = nums.size();
 2while (left+1 < right) {
 3    int mid = (left+right)/2;
 4    if (nums[mid] < target)
 5        left = mid;
 6    else right = mid; // mid >= target
 7}
 8if (right < nums.size() && nums[right] == target)
 9    return right;
10
11return -1;

時間複雜度!!!

  • 最差情況：O(log n)，即目標值在頭尾或緊鄰切第一刀處，要找尋 log₂ n 次，時間複雜度為 O(log₂ n)=O(log n)。
  • 最佳情況：O(1)，即目標資料切第一刀處，一找就找到。
  • 平均情況：O(log₂ n)=O(log n)。

空間複雜度!!!

視實際執行方式而異：

  • 迴圈法：O(1)，僅在原陣列內劃定範圍並進行比較、搜尋，不需額外儲存空間。
  • 遞迴法：O(log n)，需要額外空間儲存遞迴過程產生的堆疊（stack）。

排序!!!

氣泡排序、插入排序、選擇排序是三種概念較簡單的排序方式，空間複雜度皆僅要 O(1)，但平均時間複雜度皆達 O(n²)，除非要處理的資料量少，否則實務上少有應用。

Bubble Sort

由後而前依序將兩兩相鄰的值互相比較，直到所有的值都被排到正確的位置為止。

CODE

 1#include <algorithm>
 2void bubbleSort(vector <int>& arr) {
 3    for (int i=0; i<=arr.size()-2; ++i) {
 4        for (int j=arr.size()-1; j>=(i+1); --j) {
 5            if (arr[j-1] > arr[j]) {
 6                std::swap(arr[j-1], arr[j]);
 7            }
 8        }
 9    }
10}

時間複雜度

氣泡排序使用雙層巢狀迴圈（nested loop），外層 i 從第 0 項走到 (arr.length-2) 項（次末項），在 i 之前的值代表已經排序好的資料；內層 j 從第 (arr.length-1) 項（最末項）開始走到第 (i+1) 項，用來將相鄰的值兩兩配對比較。現假設陣列中共有 (n+1) 筆資料（索引值從 0 到 n），時間複雜度分析如下：

  • 最差情況：O(n²)，若原陣列排序正好與目標順序完全相反，所有的值都被調換，最末項調換 n 次、次末項調換 (n-1) 次…第 1 項調換 1 次、第 0 項調換 0 次，全部共調換 [n+(n-1)+…+1+0] = [(n+0)*(n+1)]/2 = (n²+n)/2 次，O((n²+n)/2)=O(n²)。
  • 最佳情況：O(n)，若原陣列排序正好與目標順序完全相同，即 i 從第 0 項走到次末項，內層 j 的項目不需要執行，因此一共只有 (n-1) 個運算步驟，時間複雜度為 O(n)。
  • 平均情況：O(n²)，因使用巢狀迴圈，因此多數情況下會有 n*n 個運算步驟。

空間複雜度

O(1)，在排序過程中，資料只在原陣列當中比較、調換，需要的儲存空間固定，不需額外空間暫存資料（在位）。

Insertion Sort

CODE

 1void insertionSort(vector <int>& arr) {
 2    for (int flag=1; flag<arr.size(); ++flag) {
 3        int key = arr[flag], e = flag - 1;
 4        while (e>=0 && arr[e]>key) {
 5            arr[e+1] = arr[e];  // 重点！！！
 6            --e;
 7        }
 8        arr[e+1] = key; //??
 9    }
10}

为什么是arr[e+1] = arr[e]？

虽然e = flag - 1，但是arr[flag]被key利用，只能从不断变化的被比较值arr[e]及其后一位arr[e+1]入手.

時間複雜度

選擇排序使用雙層巢狀迴圈（nested loop），外層 j 從第 1 項走到 (arr.length-1) 項（最末項），在 j 之前的資料代表已經當過「key」；內層 i 從第 (j-1) 項開始走到第 (-1) 項，用來將資料中所有的值逐一跟「key」比較，以找出「key」的正確位置。現假設陣列中共有 (n+1) 筆資料（索引值從 0 到 n），時間複雜度分析如下：

  • 最差情況：O(n²)，若原陣列排序正好與目標順序完全相反，所有的值都被調換，第 0 項調換 1 次、第 1 項調換 2 次…次末項調換 (n-1) 次、最末項調換 n 次，全部共調換 [1+2…+(n-1)+n] = [(1+n)*n]/2 = (n+n²)/2次，O((n+n²)/2)=O(n²)。
  • 最佳情況：O(n)，若原陣列排序正好與目標順序完全相同，即 j 從第 1 項走到最末項，內層迴圈比較 i 與「key」不需執行，因此一共只有 (n-1) 個運算步驟，時間複雜度為 O(n)。
  • 平均情況：O(n²)，因使用巢狀迴圈，因此多數情況下會有 n*n 個運算步驟。

空間複雜度

在位，O(1)。

Selection Sort

在所有資料值中，依序找出最符合目標條件者先排，直到每筆資料都被放到正確的位置為止。

CODE

1#include <algorithm>
2void selectionSort(vector <int>& arr) {
3    for (int i=0; i<=arr.size()-2; ++i) {
4        int min = i;
5        for (int j=i+1; j<=arr.size()-1; ++j)
6            if (arr[j] < arr[min]) min = j;
7        std::swap(arr[i], arr[min]);
8    }
9}

時間複雜度

  • 最差情況：O(n²)
  • 最佳情況：O(n)
  • 平均情況：O(n²)

空間複雜度

在位，O(1)。

 1// 自底至上merge sort
 2class Solution {
 3public:
 4    ListNode* sortList(ListNode* head) {
 5        if (head == nullptr) {
 6            return head;
 7        }
 8        int length = 0;
 9        ListNode* node = head;
10        while (node != nullptr) {
11            length++;
12            node = node->next;
13        }
14        ListNode* dummyHead = new ListNode(0, head);
15        for (int subLength = 1; subLength < length; subLength <<= 1) {
16            ListNode* prev = dummyHead, *curr = dummyHead->next;
17            while (curr != nullptr) {
18                ListNode* head1 = curr;
19                for (int i = 1; i < subLength && curr->next != nullptr; i++) {
20                    curr = curr->next;
21                }
22                ListNode* head2 = curr->next;
23                curr->next = nullptr;
24                curr = head2;
25                for (int i = 1; i < subLength && curr != nullptr && curr->next != nullptr; i++) {
26                    curr = curr->next;
27                }
28                ListNode* next = nullptr;
29                if (curr != nullptr) {
30                    next = curr->next;
31                    curr->next = nullptr;
32                }
33                ListNode* merged = merge(head1, head2);
34                prev->next = merged;
35                while (prev->next != nullptr) {
36                    prev = prev->next;
37                }
38                curr = next;
39            }
40        }
41        return dummyHead->next;
42    }
43
44    ListNode* merge(ListNode* head1, ListNode* head2) {
45        ListNode* dummyHead = new ListNode(0);
46        ListNode* temp = dummyHead, *temp1 = head1, *temp2 = head2;
47        while (temp1 != nullptr && temp2 != nullptr) {
48            if (temp1->val <= temp2->val) {
49                temp->next = temp1;
50                temp1 = temp1->next;
51            } else {
52                temp->next = temp2;
53                temp2 = temp2->next;
54            }
55            temp = temp->next;
56        }
57        if (temp1 != nullptr) {
58            temp->next = temp1;
59        } else if (temp2 != nullptr) {
60            temp->next = temp2;
61        }
62        return dummyHead->next;
63    }
64};

算法效率分析

渐进符号

  • O：确定时间上限
  • Ω：确定时间下界
  • Θ：同时界定上下限

时间效率分析

规律

加法取最大，乘法黍相乘
O(f(n)+g(n)) = O(max(f(n),g(n)))
O(f(n)×g(n)) = O(f(n)*g(n))

循环结构 (Loops)

  • O(n)： 线性增长。例如 for (int i=0; i < n; i++)。步长是固定加法。
  • O(logn)： 倍增或倍减。例如 while (i < n) { i *= 2; }。
  • O(√n)： 平方根。例如 for (int i=0; i*i < n; i++)。

分支语句 (If-Else)

  • 这里有个误区：分支语句通常不相乘。
  • 复杂度取其大： 在 if-else 中，复杂度取决于执行时间最长的那个分支。
  • 例子： 如果 if 里跑 O(n)，else 里跑 O(1)，则总复杂度是 O(n)。

递归 (Recursion)

  • 公式： 递归深度×每次递归的操作次数。
  • 技巧： 看到每次递归规模减半（如二分查找），通常带 logn；看到每次递归分出两个支路（如斐波那契），通常是指数级 O(2√n)。

递归周边技巧

如何求解关系式？

特征方程法（作业1）

递推式形如$F(n)=aF(n−1)+bF(n−2)$，没有与 n 相关的常数项或多项式尾巴。

  1. 设通解：假设解为指数形式$F(n)=r^n$。
  2. 写方程：代入原式化简，得到一元二次特征方程$r^2−ar−b=0$。
  3. 求特征根并写通式： 若有两个不同实根 $r_1,r_2$，则通解形式为$A r_1^n + B r_2^n$。
    若有二重根$r$，则通解形式为$F(n)=(A+Bn)r^n$。
  4. 定系数：代入初始条件（如$F(0)$和$F(1)$），解二元一次方程组求出$A$和$B$。

分治-变量代换+迭代法（作业2）

递推式内部有缩小规模的除法，形如$x(n)=ax(\frac{n}{b})+f(n)$。

  1. 为消除分式，令$n=b^k$，定义新函数$y(k)=x(b^k)$，原递推式转化为$y(k)=ay(k-1)+f(b^k)$。
  2. 递归迭代$y(k)$至$y(0)$，求得$y(k)$表达式。
  3. 由$n=b^k$得$k=log_bn$，代入得$x(n)$关系式。

建模+展开求和（作业3~5）

给定一段伪代码，要求分析其时间复杂度、特定操作的执行次数。

  1. 观察 if 语句：当 $n=1$ 时，基本操作（如乘法或比较）的执行次数。
  2. 观察 else 语句：当前层为了得到结果，执行了几次递归调用？又在当前层执行了几次基本操作？写出 $C(n)$ 和 $C(n−1)$ 的关系。
  3. 使用反向替换法不断展开式子，通常最后会转化为一个等差数列求和或常数求和的问题。
