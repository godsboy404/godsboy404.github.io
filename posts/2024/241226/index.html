Run XV6 on MacOS (ARM64)

2024-12-26

预准备

THE MOST IMPORTANT

请确保你已连接国际互联网，并有能力阅读英文资料，且愿意为自己的行为负责，否则请勿继续阅读，以避免不必要的损失！！！

Install Intergrated Tools

  • Feel free to paste the following magic words to the Terminal and hit ⏎:
1xcode-select --install

Install Homebrew

  • Next, run the following code to install the package manager :
1/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • Check if Homebrew is ready: brew doctor
    If it’s not, STFW to solve the problem and head back here @anytime.

Install Packages

  • All you have to do is run the following prompts one by one, and it SHOULD works fine. At least my machine works fine:）
    If your computer has some mysterious problems, I’m afraid you’ll have to work on your own:-（
1brew install python3 gawk gnu-sed gmp mpfr libmpc isl zlib expat texinfo flock libslirp qemu
2brew tap riscv-software-src/riscv
3brew install riscv-tools riscv64-elf-gdb
4git clone https://github.com/mit-pdos/xv6-riscv.git
5cd xv6-riscv
6export PATH="/opt/homebrew/opt/riscv-gnu-toolchain/bin:$PATH"
7source ~/.zshrc
  • You‘ll have to downgrade gcc for xv6,
1brew unlink i386-elf-binutils
2brew unlink gcc
3brew link --overwrite riscv-gnu-toolchain
4brew link --overwrite riscv-gnu-toolchain --dry-run
5riscv64-unknown-elf-gcc --version

Building the OS

Run following commands:

  • make clean
  • make
  • make qemu

The output should looks like this:

1hart 2 starting
2hart 1 starting
3init: starting sh
4$

To exit from QEMU kernel, press control⌃+A and then press X.

You will be encountered with error if you don’t downgrade gcc. Once downgraded, your codes won’t run on Code Editors. So after successfully booting of xv6, you can run brew link gcc to get back to the correct lane!
